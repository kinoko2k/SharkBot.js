# SharkBot.js

Discordの多機能Bot<br />
このリポジトリは、SharkbotのソースコードをJavaScriptに書き換えて最適化したものです。<br />
動作確認はしているので、動くとは思いますが、元リポジトリで実行したほうがいいでしょう。

## 主な機能

・グローバルチャット<br />
・グローバル宣伝<br />
・モデレーション<br />
・画像・テキストの加工<br />
・様々なツール<br />
・ほかのBotの招待リンク作成<br />
・ロールパネル・認証パネル<br />
・アンケート機能<br />
・Bump・Up通知<br />
・留守番機能<br />
・スターボード<br />
・カウント、経済<br />
・イベント通知、時報<br />
・チケットやWeb上で会話できるチケット<br />
ほかにもいっぱい！<br />
